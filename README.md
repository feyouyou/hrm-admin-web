# hrm-admin-web

## Introduction
```
这是一个人事管理系统前端页面，数据使用MockJs拦截返回
构建工具：webpack
css预处理器：sass
集成 typescript
技术栈：react + react-router + react-redux
```

## Project setup
```
pnpm install
```

### Compiles and hot-reloads for development
```
pnpm run dev
```

### Compiles and minifies for production
```
pnpm run build
```
